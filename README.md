# SimplificaPsi

Sistema de Agentes AI para Gestão de Consultórios Psicológicos

## Descrição

SimplificaPsi é um sistema inteligente que utiliza agentes de IA para automatizar e otimizar a gestão de consultórios psicológicos, incluindo agendamento de clientes, controle financeiro e cadastro de clientes.

## Tecnologias

- Python 3.11+
- Pydantic AI
- FastAPI
- PostgreSQL
- Redis
- Docker

## Desenvolvimento

```bash
# Setup inicial
make setup

# Desenvolvimento
make dev

# Testes
make test

# Docker
make docker-up
```
